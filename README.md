# Excel Projects_Data Analytics
These projects demonstrate my Excel skills
### Introduction
This project uses real-world data from 2023. I practiced using this YouTube channel: Luke Barousse.

Dataset: data_jobs_salary_all.xlsx
The data includes detailed information on job titles, salaries (yearly and hourly), locations, required skills, job type, etc.

There are two projects in this section:
1. Yearly Salary Dashboard
2. Salary Analysis
